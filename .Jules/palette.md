## 2024-05-16 - Form Validation & Accessibility Improvements
**Learning:** In this application, form validation errors automatically disappeared via a timeout, which was confusing and inaccessible for users. Also, inline styles and `aria-invalid` attributes must be explicitly reset when clearing form errors to ensure the UI correctly reflects the corrected state. Icon-only buttons often miss `aria-label` attributes.
**Action:** Removed automatic timeout for form validation errors, requiring user interaction to clear them. Added an `input` event listener to explicitly clear `aria-invalid` and inline styles when correcting form input. Added an `aria-label` to the `#backToStartBtn` icon-only button for better accessibility. Always ensure error states remain until resolved and that all styles and accessibility attributes are correctly reset when doing so.
