## 2024-05-24 - Form Error Persistence & Accessibility
**Learning:** Automatically clearing form validation errors via timeout creates a frustrating experience as users may not have time to read the error or see what field caused it before it vanishes. Additionally, lacking ARIA associations (`aria-invalid` and `aria-errormessage`) leaves screen reader users unaware of the specific input failure state.
**Action:** When displaying form validation errors, persist the error message and red border until the user explicitly interacts with the input (e.g., via the `input` event). Ensure the input receives `aria-invalid="true"` and an `aria-errormessage` linking to an error container with `role="alert"`. When clearing the error on input, explicitly reset the `aria-invalid` attribute and any inline styles like `borderColor` to properly reflect the corrected state.
