## 2024-05-18 - Persistent and Accessible Form Validation Errors
**Learning:** When displaying form validation errors (e.g., in `static/app.js`), automatically removing them via a timeout (e.g., 2 seconds) creates a poor experience and accessibility barriers. Screen readers may not have enough time to announce the error, and users might forget what the error was before they can correct it. Additionally, ARIA attributes like `aria-invalid` and visual cues (like `borderColor`) must be explicitly managed.
**Action:** Errors should persist until the user interacts to correct the input. Remove automatic timeouts for form errors. Implement an `input` event listener to explicitly clear the error state (including removing `aria-invalid` and resetting inline styles like `borderColor`) as soon as the user starts correcting the problem.
