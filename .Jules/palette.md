## 2026-04-22 - Improve Form Error Clearing UX and Accessibility
**Learning:** Automatically hiding validation errors after a short timeout is frustrating for users and breaks accessibility guidelines, especially if the user hasn't finished correcting their input. Connecting error messages to input fields with `aria-errormessage` and using `role="alert"` is essential for screen readers to announce errors effectively. Furthermore, resetting error states dynamically on the `input` event provides immediate, satisfying feedback that the user is addressing the problem.
**Action:** Always link validation errors directly to their associated inputs using `aria-errormessage` and `role="alert"`. Never use timeouts to hide validation errors; instead, clear them dynamically when the user starts typing to correct their input (e.g., using an `input` event listener).
