## 2024-05-14 - Persisting form validation errors until user action
**Learning:** Form validation errors that automatically clear via timeout can be disorienting and inaccessible. Users may miss the error message if they are slow to read or if using a screen reader. Furthermore, the input field should explicitly clear its `aria-invalid` state and styling only when the user corrects it. When using `role="alert"`, `aria-live="polite"` should not be added to prevent screen reader conflicts.
**Action:** Remove automatic timeouts for form errors. Bind error clearance to an explicit user `input` event on the affected field. Link the input to the error message with `aria-errormessage` and set `role="alert"` on the error container. Use `aria-invalid="true"` on the input while the error is active.
