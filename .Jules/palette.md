## 2024-05-24 - Persisting Form Validation Errors
**Learning:** Automatically hiding form validation errors via `setTimeout` creates an accessibility and usability barrier. Users, especially those using screen readers or with cognitive disabilities, may miss the error message if it disappears too quickly. Additionally, missing `aria-invalid`, `aria-errormessage`, and `role="alert"` attributes prevent screen readers from properly conveying the error state to the user.
**Action:** When implementing form validation, always persist the error state (both visually and via `aria-invalid="true"`) until the user actively corrects the input (e.g., clear the error on the `input` event). Ensure the input field is linked to its error message container using `aria-errormessage="[id]"` and set `role="alert"` on the error container to announce it dynamically without conflicts.
