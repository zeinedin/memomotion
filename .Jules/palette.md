## 2024-05-18 - Persistent and Accessible Form Validation Errors
**Learning:** Automatically hiding form validation errors via timeouts (e.g., `setTimeout`) creates significant accessibility and usability issues. Users, especially those using screen readers or those with cognitive disabilities, may miss the error message or forget what the error was before correcting it. Furthermore, simply applying visual cues (like `borderColor`) without corresponding ARIA attributes (`aria-invalid="true"`) fails to convey the error state semantically.
**Action:** Always persist form validation errors until the user attempts to correct the input (e.g., binding to the `input` event). When an error occurs, explicitly set `aria-invalid="true"` on the input field and link it to an error container using `aria-errormessage`. Ensure the error container has `role="alert"` so it is immediately announced by screen readers.
