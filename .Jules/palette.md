## 2024-04-15 - Improve Form Validation Error Persistence and Accessibility
**Learning:** Automatically hiding validation errors (via timeouts) creates a poor user experience, especially when the invalid state is not clearly communicated to screen readers. Relying solely on visual cues (like a red border) without corresponding ARIA attributes (`aria-errormessage`, `role="alert"`, and `aria-invalid`) creates accessibility barriers for screen reader users, leaving them unaware of why form submission failed.
**Action:** When implementing form validation, ensure errors persist until the user explicitly takes corrective action (e.g., via the `input` event). Always link error containers with `aria-errormessage` and use `role="alert"`. Additionally, explicitly manage the `aria-invalid` state via JavaScript along with any visual cues.
