## 2024-05-24 - Form Error Persistence and Custom Button Group Accessibility
**Learning:** We observed that form validation errors (like the "Team Name required" message) were automatically disappearing after a short 2-second timeout, which is detrimental to user experience. The error states must persist until the user actively corrects their input. Furthermore, using custom div structures as button groups requires explicit `role="group"` and manual management of the `aria-pressed` state for assistive technologies to correctly perceive selections, as `role="radiogroup"` is not suited for standard `<button>` tab navigation flow.
**Action:** Always ensure that form error messages and their corresponding `aria-invalid` states are cleared via active user input (e.g., binding to the `input` event) rather than arbitrary timeouts. Use `role="group"` with explicit `aria-labelledby` when creating custom button clusters, and manually toggle `aria-pressed` values via JavaScript.
