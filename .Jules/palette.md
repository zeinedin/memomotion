## 2024-05-15 - Improve Form Validation UX and Accessibility
**Learning:** For optimal accessibility and user experience, form error states shouldn't arbitrarily disappear on a timeout. They need to be linked to their input fields via `aria-errormessage` and use `role="alert"` so screen readers announce them properly. Furthermore, the error state (both styling and `aria-invalid`) should remain until the user interacts with the input (e.g. by listening to the `input` event) to give them adequate time to read and correct the mistake.
**Action:** Always map validation message elements using `aria-errormessage` combined with `role="alert"`. Listen to the `input` event to dynamically remove error classes and reset `aria-invalid` to `"false"` rather than using arbitrary timeouts.
