## 2024-05-24 - Form Validation Error Accessibility
**Learning:** When displaying inline form validation errors, they must be programmatically linked to the input field using `aria-errormessage` to ensure screen readers associate the error with the correct field. The error container must have `role="alert"` so it's announced when displayed. Additionally, visually hiding and removing the error (e.g., on input) should clear both visual cues (like `borderColor`) and programmatic states (`aria-invalid="true"`). The error message should persist until the user actually corrects the input, rather than disappearing automatically after a timeout.
**Action:** Always link form errors to their inputs using `aria-errormessage="[error-id]"` and `aria-invalid="true"`, ensuring the error container has `role="alert"`. Clear both visual and ARIA states simultaneously on the `input` event when the user modifies the field.
