## 2024-05-18 - Form Validation Accessibility & Persistence
**Learning:** Automatically hiding form validation errors via timeout (e.g. 2000ms) creates a frustrating experience as users lose the context of the error before they can fix it. Additionally, error messages lacking proper ARIA associations (`aria-errormessage` on input, `role="alert"` without `aria-live="polite"` on container) fail to alert screen reader users effectively. Finally, inline styles clearing the error state must explicitly reset `aria-invalid` to false when the user rectifies the input.
**Action:** Always persist form validation errors until the user corrects the input (e.g., clear on `input` event). Ensure error containers use `role="alert"` (without `aria-live="polite"` to avoid conflicts) and are linked to the input via `aria-errormessage`.
