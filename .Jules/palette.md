## 2026-04-03 - Form Validation Accessibility and UX Improvement
**Learning:** Automatically hiding form validation errors via timeout (`setTimeout`) creates accessibility issues because screen reader users may not have enough time to hear the error before it disappears, and sighted users might lose track of why the form submission failed. Also, modifying inline styles without managing the corresponding ARIA state (`aria-invalid`) breaks the semantic connection.
**Action:** Always persist form validation errors until the user takes action to correct them (e.g., listening to the `input` event). Always explicitly link the input field to its error message container using `aria-errormessage` and `role="alert"`, and manage the `aria-invalid` state concurrently with any visual error styling changes.
