## 2024-03-30 - Form Validation Persistence and ARIA Association
**Learning:** Automatically hiding form validation errors via a timeout can negatively impact accessibility by giving users too little time to read the error and correct their input. In addition, explicit ARIA associations such as `aria-errormessage` and `aria-invalid` must be used to link the input directly to its error container, while manually cleaning up these states on input correction or screen navigation. Using `aria-live="polite"` inside an element with `role="alert"` can cause redundant or conflicting announcements for screen readers.
**Action:** Replace timeout-based error clearing with event-driven clearing (e.g., listening for `input` events). Always link input fields to error messages using `aria-errormessage`, update `aria-invalid` dynamically, apply `role="alert"` strictly to the container without `aria-live="polite"`, and ensure all these states and inline styles are explicitly cleared when navigating away or correcting the input.
